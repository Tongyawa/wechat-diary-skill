# 文件附件

daily、bulk、补跑和按需导出默认保存本机能核验的文件附件。只认 XML 中的 MD5 和字节数同时相符；不按原名猜配，不触发客户端下载。缺文件仍产出聊天，不改变日常、批量和默认按需的退出码。

```toml
[file_attachments]
enabled = true
sources = []
```

`enabled` 是总开关，公开默认开启。`sources` 是有序的本机只读目录列表；相对路径以 config 所在目录为准。空列表回退 `[favorites].account_dir` 的 `msg/file`；按需额外兼容旧 `[on_demand].files_root`，优先于账号目录退路。归档 `[paths].archived/raw/_media/files/` 自动加入来源，并先按 MD5 分片查询，避免全库扫描。目录均未配置且归档没有对象时提示一次“未配置文件来源，文件只记标签”。无文件消息不扫描目录；关闭后各入口不读取来源、不创建新文件 CAS 或原名副本。

文件写入导出根的 `_media/files/<md5前2位>/<md5>.<ext>`，消息 `source` 使用相对 JSON 的 `../_media/files/...`。扩展名取消息原名最后一个后缀的小写：1–16 位 ASCII 字母数字且含字母，否则为 `bin`；同一批同 MD5 的不同原名优先非 bin 的最小后缀。归档已有对象时复用既有后缀，确保与离线补写一致。已有对象先核对 MD5 和大小。processed 仍显示 `[文件] 名字`。

每轮打印一行按文件消息计数的汇总：“文件 N 条：取到 a，本机没有 b，无 MD5 c”。缺大小或校验不符计入本机没有；扫描或复制异常不会冒充取到。批量另打印来源索引耗时。

按需还默认生成会话 `files/README.md` 和逐条 `manifest.json`，保留原名，同名异内容增加 `(n)`。默认缺文件退出码 0；显式 `--include-files` 维持完整性要求，缺失或扫描异常退出码 3。`--files-root` 为本次覆盖普通来源；归档 CAS 仍可使用。`--no-files` 只关闭本次，和 `--include-files` 互斥；总开关关闭时两类文件产物都关闭。

daily、bulk、改名摄取和按需追加始终保留同身份文件消息的已有非空 `source`，即使总开关关闭。只做“归档非空、新来为空”这一方向；两侧非空不同仍由原有摄取护栏判断。身份沿用同代 `(createTime, localId)`、跨代完整平台消息 ID；重复身份不猜配。计划保留输入原字节指纹与发布字节指纹，执行前重验原件，发布后核对合成字节。JSON 附件作为不透明媒体，不参与聊天、朋友圈或群名字发现。
